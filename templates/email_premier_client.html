Premier client payant !

Un client vient de payer son premier mois. Comme convenu, vous pouvez maintenant activer les résumés IA des appels d'offres : ils coûtent environ 5 € par mois, largement couverts par ce client. Rien n'est dépensé tant que vous ne faites pas ces étapes.

  1. Ouvrez console.anthropic.com et créez un compte (ou connectez-vous).
  2. Menu Billing : ajoutez votre carte et achetez 5 $ de crédit. Laissez la recharge automatique désactivée : la dépense ne peut pas dépasser ce montant.
  3. Menu API Keys : bouton Create Key, nommez-la « radar », copiez la clé (elle commence par sk-ant-).
  4. Sur GitHub, dépôt radar-marches : Settings, puis Secrets and variables, puis Actions, bouton New repository secret. Nom : ANTHROPIC_API_KEY, valeur : la clé copiée. Enregistrez.

C'est tout : dès le lendemain matin, les alertes contiennent un résumé clair et une note d'accessibilité pour chaque marché, et le site l'annonce. Si vous préférez, dites simplement à Claude dans le projet « active les résumés IA » et il vous guidera.
